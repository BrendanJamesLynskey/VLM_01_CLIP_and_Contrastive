# VLM 01 — CLIP & Contrastive Vision-Language Learning

A deep-technical presentation deck covering CLIP, OpenCLIP, EVA-CLIP, and SigLIP: how contrastive pre-training aligns image and text in a shared embedding space, the InfoNCE and sigmoid loss formulations, scale curves from the DataComp benchmark, zero-shot classification and retrieval, and how CLIP became load-bearing infrastructure in modern text-to-image and VLM systems.
